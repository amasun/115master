# UI / 功能优化计划

基线：`v2` 分支。以下为独立于 markers（T1–T5）的功能优化项，按优先级排列。

---

## OPT1：演员头像缩位匹配降级

### 背景

演员头像匹配目前因中日文写法差异（如汉字 vs 假名）容易匹配不到演员。需要一个渐进式降级策略，在精确匹配失败时逐步缩短搜索词，提高命中率。

### 需求

当完整名字匹配不到结果时，按以下顺序降级：

1. 完整名字搜索（如 `1234`）
2. 去掉末位搜索（如 `123`）
3. 继续去位搜索（如 `12`，取第一候选）

每一步只在上一步无结果时才执行；一旦命中即停止降级。若降级到最短位数（2位）仍无结果，则判定为匹配失败返回 undefined。

### 范围

- 修改演员头像匹配逻辑（搜索 / 缓存层）
- 补单测覆盖降级链路：完整命中、一级降级、二级降级、全部失败

## OPT2：视频文件列表头像显示修正与文件夹图标替换（已完成）

### 背景

当前头像（avatar）会同时出现在文件夹和视频文件左侧，且在文件夹中与原生图标并排显示容易造成文字错位。期望头像仅在文件夹场景出现（视频文件不显示），且文件夹匹配到演员时直接替代原生文件夹图标。

### 需求

- 视频文件列表项（非文件夹）彻底禁止加载和渲染演员头像
- 文件夹列表项匹配到演员头像时，隐藏原生文件夹图标，直接将演员头像作为文件夹图标展示
- 组件卸载时恢复原生文件夹图标显示

### 范围与实现

- 在 `FileItemModActressInfo.onLoad` 增加 `file_type !== FileType.folder` 拦截门禁
- 旧版与新版分别隐藏原生文件夹图标并前置挂载 50×50 圆形演员头像
- `onDestroy` 恢复原生图标状态
- 补全单测与 E2E 测试覆盖：视频无头像、文件夹头像替代原生图标、重绘自动恢复与卸载还原

---

## OPT3：预览按钮功能合并

### 背景

当前预览按钮功能单一，需要扩展为同时控制视频截图和作品介绍。

### 需求

预览按钮点击后应能：

- 触发视频截图
- 展示 / 切换作品介绍信息

### 范围

- 扩展预览按钮的点击处理逻辑
- 确认 UI 能容纳两种功能的切换或并行展示
- 补交互测试

---

## OPT4：设置项同步到原生界面

### 背景

整体设置目前只在 Fusion 独立浏览器环境中可用。用户在 115 原生界面中使用脚本时，无法访问和同步这些设置项。

### 需求

- 在 115 原生界面中暴露与 Fusion 独立浏览器一致的设置入口
- 设置数据在两端保持同步（共享存储或同步机制）
- 设置项的变更在任一端生效后，另一端可感知

### 范围

- 抽取设置数据模型为通用层（不依赖 Fusion 独立环境）
- 原生界面注入设置面板
- 存储共享策略（localStorage 命名空间一致 或 GM storage）
- 补同步测试

---

## 优先级与依赖

| 任务 | 优先级 | 依赖 |
|------|--------|------|
| OPT1 演员缩位匹配 | 高 | 无 |
| OPT2 视频头像修正 | 中 | 无 |
| OPT3 预览按钮合并 | 中 | 无 |
| OPT4 设置同步原生界面 | 低-中 | 需评估存储共享方案 |

OPT1–OPT3 互相独立，可并行开发。OPT4 需要先确定存储共享方案再动手。
