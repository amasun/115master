# T2：播放器打点界面、快捷键、视频页接入（仅本地持久化）

背景：先阅读 `docs/agy/plan.md` 的"分层""播放器 UI"，以及 `AGENTS.md`、`.agents/STYLE_GUIDE.md`、`apps/monkey/AGENTS.md`、`docs/agents/component-stories.md`。T1 已完成，纯逻辑在 `apps/monkey/src/utils/markers/`，本地存储在 `apps/monkey/src/utils/cache/markerStore.ts`，直接复用，不要重写。

注意命名：已有的 `pages/video/data/useDataMark.ts` 是"收藏"。本功能一律叫 `marker` / `Markers`。

## 要做什么

### 1. 视频页数据层：`apps/monkey/src/pages/video/data/useDataMarkers.ts`
- 入参：`pickCode`（ref）以及取文件信息的方式（`file_id`、`file_name`、时长，来自 `useDataFileInfo` 的 `DataFileInfo.state`）。
- 行为：`pickCode` 变化时从 `markerStore` 加载对应 `MarkerDoc`（没有则在首次打点时用 `createDoc` 创建）；暴露
  `markers`（`visibleMarkers` 的结果，响应式）、`add(time, label?)`、`update(id, patch)`、`remove(id)`；每次变更后保存到 `markerStore`（保存失败时用现有的提示方式报错，不要静默）。
- 切换视频时不能把上一个视频的打点写到新视频上（注意异步加载竞态）。
- 保存前调用 `pruneTombstones`。
- 把可测的部分（加载竞态、增删改后保存）写单测：`apps/monkey/src/pages/video/data/__tests__/useDataMarkers.test.ts`（文件名需包含 `marker`）。

### 2. XPlayer 接口（保持通用，不直接接触存储）
- 新增 prop `markers`（`{ id, time, endTime?, label }[]`，默认空数组）和事件 `markerAdd(time)`、`markerUpdate(id, patch)`、`markerRemove(id)`。沿用 XPlayer 现有 props / emits 的定义和透传方式（见 `hooks/usePlayerProvide.ts` 的 `rootProps` / `rootEmit`）。
- 新增 `hooks/useMarkers.ts` 并挂到 `PlayerContext`：提供 `list`、`addAtCurrentTime()`、`seekTo(marker)`、`seekPrev()`、`seekNext()`（用 T1 的 `findPrevMarker` / `findNextMarker`）、`update`、`remove`。跳转用 `ctx.playerCore.value?.seek(time)`，操作后用 `ctx.hud.show(...)` 给反馈（例如"已打点 12:34""打点：<备注>""没有更多打点"）。

### 3. 进度条刻度：`components/Controls/ProgressBar.vue`
- 在 wrapper 层（不是带 `overflow-hidden` 的 track）增加一层绝对定位的刻度，水平位置 `time / duration`（duration 未知或为 0 时不渲染）。
- 刻度要有足够的点击热区；悬停显示备注（无备注显示时间）；点击跳转到该打点，且不能触发进度条自身的拖拽 / 点击跳转逻辑。
- 不影响现有的悬停缩略图预览和拖拽。

### 4. 控制栏按钮 + 列表：新建 `components/Controls/MarkersButton.vue`
- 仿照 `components/Controls/PlaybackRateButton.vue`（`Button` + `Popup` + `usePlayerContext()` + `shortcuts.getShortcutsTip` 作为 title）。放在 `ControlBar.vue` 右侧按钮组里合适的位置。
- 弹层内容：顶部"在当前位置打点"按钮；下方按时间排序的打点列表，每行显示时间（`formatMarkerTime`）、备注，点击行跳转；每行可改备注（行内输入，回车保存，Esc 取消）和删除。空列表显示空状态文案。
- 输入框聚焦时，播放器快捷键不能被触发（按键不应被当作快进、暂停等）。
- 图标按项目规范在图标注册表里集中定义后使用。

### 5. 快捷键
- 在 `components/Shortcuts/shortcuts.actions.ts` 增加三个动作：`addMarker`、`prevMarker`、`nextMarker`，放进一个合适的现有分组或新增"打点"分组（`shortcuts.const.ts` 的 `ACTION_GROUPS`）。
- 在 `DEFAULT_ACTION_KEY_BINDINGS` 给出默认按键：`addMarker` → `M`，`prevMarker` → `[`，`nextMarker` → `]`。**先检查是否与现有默认绑定冲突**；若冲突，冲突的那个动作默认留空 `[]`，并在结束报告里说明。
- 设置页的快捷键列表会自动列出新动作，确认名称为中文且可读。

### 6. 视频页接入：`apps/monkey/src/pages/video/index.vue`
- 用 `useDataMarkers` 取数据，把 `markers` 传给 `<XPlayer>`，把三个事件接到 `add` / `update` / `remove`。

### 7. 测试与 changeset
- 组件 / hook 的单测放在 XPlayer 下对应的 `__tests__` 目录，文件名包含 `marker`（例如 `Controls/__tests__/markers.test.ts`），至少覆盖：有打点时渲染刻度及其位置、点击刻度触发 seek、`seekPrev` / `seekNext` 的行为、列表增删改会发出对应事件。参考已有的 `Controls/__tests__/Controls.test.ts` 的写法。
- 若项目规范要求新组件配 story（见 `docs/agents/component-stories.md`），按规范补上。
- 新增 `.changeset/markers-player-ui.md`（`'@115master/monkey': minor`）。
