# 115 master fusion+ 主要功能总览

本文档按功能模块介绍 `115 master fusion+` 的全部用户能力，包含继承自上游 `115master`（`@cbingb666`）与 `115master-fusion`（`@daoran9`）的核心基础功能，以及本版新增与重构的影院级片库、搜索与清理功能。

---

> **第一部分：核心基础功能（来自 `115master` 与 `115master-fusion`）**

## 1.1 115 旧版网盘增强（U1）
- **文件列表增强**：在 115 官方旧版文件列表中直接展示视频时间轴多格预览截图（支持在设置中调节截图张数）与快捷播放按钮。
- **番号资料卡片**：自动识别列表内视频番号，内联渲染海报、标题、演员、发行日期、评分等作品详情，支持宽大布局与紧凑布局切换。
- **演员头像文件夹**：当文件夹名称匹配演员姓名时，自动使用演员头像替代默认文件夹图标。

## 1.2 115 新版网盘增强（U2）
- **列表数据捕获与注入**：无侵入拦截并关联 115 新版前端列表数据，为新版页面补充视频封面、番号作品资料与演员头像展示。
- **快捷入口与链接导出**：提供直达 MASTER 播放器入口与 ED2K 链接一键生成能力。

## 1.3 影院模式独立界面底座（U3）
- **独立应用容器**：内置独立 SPA 界面、路由、毛玻璃组件体系及浅色/深色/跟随系统主题管理。
- **网盘文件管理能力**：支持分页/无限滚动文件浏览、多选、移动、重命名、星标、115 标签管理与离线下载任务管理。
- **偏好设置中心**：统一管理账号状态、布局密度、各项增强开关与外观主题，修改即时生效。

## 1.4 MASTER 播放器
- **原画与多画质播放**：支持 Ultra 原画直链与多档转码画质无缝切换。
- **字幕自动搜索与加载**：内置多源字幕客户端（`Thunder` 迅雷、`SubtitleCat`、`AvSubtitles`、`Aiyi`），自动匹配并挂载外挂字幕。
- **观影交互增强**：进度条缩略图预览、同目录播放列表、播放倍速、画面比例/旋转、剧院模式/全屏/画中画、自定义快捷键以及播放页影片详情侧边栏。

## 1.5 播放器打点（Fusion Markers）
- **进度条关键点标记**：播放时一键在当前时间点打点（默认 `B`）并编辑文字备注，进度条实时渲染打点刻度与悬停预览。
- **列表管理与快捷跳转**：支持在控制栏打点面板中集中查看、重命名、删除打点，并通过快捷键（`,` / `.`）在打点间前后跳转。

## 1.6 基础番号刮削与头像库
- **多源并发对冲与融合缓存**：内置 `JavLibrary`、`JavBus`、`JavDB`、`MissAV` 及 FC2 专用源 `FD2PPV`，支持并发对冲请求、按优先级字段融合（`Fusion` 缓存）与封面降级回退。
- **演员头像数据库**：对接 `gfriends` 演员头像索引，提供本地缓存与姓名归一化匹配。

> **第二部分：本新版（`115 master fusion+`）新增核心大功能模块**

## 2.1 超级搜索与全盘扁平视频索引（Super Search & Drive Indexer）
- **跨目录全盘视频索引**：递归/批量拉取 115 全盘视频文件并在本地 IndexedDB 构建扁平化视频索引，摆脱逐级翻找目录的限制。
- **自定义多选扫描与刮削目录**：支持在设置、影视库侧栏和超级搜索中多选指定 115 文件夹作为索引与刮削范围，并可手动将各目录标记为 **「AV」** 或 **「院线」**；初次建立索引时主动引导选择目录，未选择或跳过则默认全盘扫描。
- **院线影视独立栏目与双源刮削**：侧边栏保留原有栏目不变，新增独立的 **「院线影视」** 栏目（与 AV「全部作品」及「演员」墙彻底分流隔离）；院线目录视频自动按电影/剧集聚合，支持 **TMDB API**（可选 Key 与自定义反代地址）+ **豆瓣免 Key** 双源自动刮削（TMDB 异常或超时自动回退豆瓣），支持海报墙与详情页视口自动刮削及 `2:3` 竖版海报自适应展示。
- **全量同步与安全增量同步**：支持全量重建与基于时间窗口回溯的安全增量同步；通过影视库发起离线下载后自动触发后台增量同步与新片刮削。
- **多维联合检索与原生兜底**：支持按番号、片名、文件名为线索极速检索，内置中日文演员姓名/曾用名别名映射匹配，并在本地未命中时支持 115 原生搜索兜底，提供 U1/U2/U3 三端快捷搜索入口。
- **创作者平台识别防冲突与父目录索引**：内置 `OnlyFans` / `MyFans` 显式特征与目录辅助识别，彻底阻断与常规 AV 番号的误提取和子串误命中；支持按安全节流一键索引父目录路径，提供来源平台筛选胶囊以及 `@账号`、`of:`、`mf:`、`dir:` 等快捷查询前缀。

## 2.2 真影视库模式（Media Library / 番号专线）
- **影院级海报墙主界面**：以沉浸式深色海报墙影视库作为主入口（支持从 115 旧版快捷栏一键直达），侧边栏各栏目（`全部作品`、`星标收藏`、`有打点`、`院线影视`、自定义栏目、标签栏与清理页标签）全面支持 URL 锚点同步与刷新保留；底部「网盘索引」部数旁附带悬停预估总时长统计卡片与 13 档风趣片库称号彩蛋。
- **分页切换加载与每页数量可配**：海报墙支持自定义每页显示数量（`24 / 48 / 60 / 96 / 120` 部/页，持久化保存）与分页切换加载，结合视口按需加载封面与切页自动释放资源，保障海量片库流畅度。
- **智能海报裁切、丰富卡片信息与嵌入式详情页**：自动识别双页横版封面并智能右半裁切生成高清竖版海报；AV 卡片展示精确到天的发行日期（`YYYY-MM-DD`）、可点击筛选的演员与发行商/片商、封面评分与评价人数角标以及右上角 **LTX / LADA / 无码 / 破解** 五档识别角标（按「厂商番号先判 + 文件名/手动标签冲突转破解」规则判定，有码默认无标签）；作品详情页支持预览图画廊、时间分段截图、同番号多文件版本切换、已收藏演员红心标识与快捷文件操作。
- **多维组合筛选、语义索引与排序体系**：支持按`主题 / 角色 / 服装 / 体型 / 行为 / 玩法 / 其他` 7 大分组浏览筛选题材，支持按片商、导演、发行年份、115 网盘原生颜色标签、LTX 高级去码、全来源无码及「隐藏疑似广告视频」组合筛选；关键词搜索内置 LTX / 无码语义索引，支持按评分（含评价人数决胜）、发行日期、最近入库、片长、体积、番号排序。
- **自定义封面与演员头像**：支持从多源候选中手动切换作品封面/演员头像，或上传本地图片自动压缩持久化。

## 2.3 影院浮窗播放器与打点备注云同步
- **影视库内嵌浮窗播放器**：在影视库内点击播放时直接拉起顶层影院浮窗播放器，无需离开当前海报墙/详情筛选上下文即可流畅观影。
- **播放打点同步至 115 原生备注**：支持将本地播放打点自动序列化写入 115 文件原生备注（含旧本地打点打开视频时自动补写），实现换浏览器/换设备打开同一视频自动恢复打点，并在播放器内直观展示当前打点保存方式标签。

## 2.4 演员图片墙与多源个人资料
- **独立演员图片墙**：按作品数量与收藏权重聚合本库演员，支持女演员/男演员筛选（默认女演员）、右键菜单手动标注性别并持久化、演员收藏置顶、隐藏演员管理、**演员备注名 & 片名备注（同步 115 原生文件备注字段）**以及演员姓名角标后缀自动清洗。
- **右侧竖型演员个人资料面板**：在演员作品墙右侧展示生日、年龄、身高、罩杯、三围、出生地、爱好、曾用名别名、本库作品统计、网盘标签与常拍题材联动筛选。
- **演员资料多源自动兜底**：按 `JavBus → AVBASE → MINNANO-AV` 顺序自动回退拉取个人资料与别名（30 天本地缓存），解除对单一站点的依赖。

## 2.5 去重与垃圾文件清理中心（Cleanup Center）
- **智能异步重复作品分析**：后台异步扫描全库重复番号与相似视频，内置误提取过滤、剧集集数识别与蓝光原盘分卷防误判，按画质/体积智能推荐保留项，并赋予 **LTX 高级去码（+180）** 与 **LADA 去码（+150）** 最高版本保留权重。
- **疑似广告视频与垃圾文件扫描**：支持自定义广告判定时长与体积阈值（与影视库过滤共用配置），并按类别扫描全盘非媒体垃圾文件。
- **高可控批量清理体验**：分页栏置底常驻、支持多维排序与底部全选；批量删除时实时展示进度条、逐目录即时刷新列表、透出具体错误/风控原因，并支持随时中断及页面关闭前防中断提醒。

## 2.6 多源元数据刮削扩展与抗风控体系
- **全场景备用刮削源扩展**：
  - 通用无日区限制兜底源：`Jav321`、`AVBASE`。
  - 细分类型优先补盲源：`MGStage`（自动识别 `SIRO`/`LUXU`/`MIUM`/`ABW` 等素人与 Prestige 前缀）、`FC2Official`（FC2 官方商品页补盲）。
  - 可选官方高清源：`FANZA / DMM`（可在偏好设置中按需开启，日本 IP 下优先获取官方无水印封面与完整元数据）。
- **低速后台刮削与负缓存保护**：支持后台队列低速自动补全未刮削作品，区分「未收录（负缓存）」与「风控/挑战/网络超时（允许重试）」。
- **115 接口抗风控熔断与降级**：目录路径反查采用单并发串行节流 + 400ms 间隔 + 触发风控 30 秒全局熔断退避；播放列表拉取异常时优雅降级并支持一键重试。

## 2.7 跨设备缓存同步与设置增强
- **跨设备缓存导入导出（`.115bak` 单文件归档）**：在偏好设置「缓存与数据同步」中支持将本地视频索引、JAV 与院线刮削元数据、刮削未命中负缓存、演员个人资料、播放打点、目录路径缓存及可选的自定义封面/头像与海报墙缩略图打包为单个 `.115bak` 二进制归档，并在其他设备上安全合并导入（同时兼容旧版 `.json` 备份）。
- **原生 115 删除联动与孤立刮削缓存清理**：在 115 原生页面删除文件或目录后立即同步移除本地视频索引并跨标签通知影视库刷新；设置页支持一键比对本地索引清理已删除影片残留的孤立刮削缓存。
- **原生 115 目录跳转版本切换**：支持在偏好设置中选择「打开所在目录」默认跳转到 **新版 115** 或 **旧版 115**（当旧版触发风控刷不出时可无缝切至新版）。

## 2.8 智能目录合集与自定义编辑
- **无番号目录自动合集**：同一非根目录文件夹下存在 `>= 2` 个非院线视频且全部未识别出番号时，自动聚合为单一合集卡片在海报墙呈现，优先以父目录名作为合集标题并跳过无意义的番号刮削与同作去重误报。
- **合集详情与自定义编辑**：点开合集卡片展示「合集视频列表」（支持按文件名、时间、体积、时长排序及直接连播）；支持在线编辑合集标题、简介、标签/题材、关联创作者及自定义封面，并支持一键「拆分为独立视频」与「恢复为目录合集」。

## 2.9 索引目录隔离与自建侧边栏目
- **AV 与院线双目录选择 + 院线默认开启**：偏好设置中将「AV / 番号影视目录」与「院线影视目录」拆分为独立选择框，院线影视栏目默认开启（可在偏好设置或侧栏右键关闭）；「全部作品」严格仅展示 AV 与默认库作品，不混入院线及自建栏目内容。
- **常驻目录入口与侧栏右键菜单**：在「全部作品」「院线影视」与自建栏目顶部栏常驻目录/栏目配置按钮，侧边栏各栏目支持右键快捷配置目录、全量重建或隐藏/删除；同步支持院线剧集按父目录名兜底解析与优先级防覆盖。
- **用户自建侧边栏目**：支持随时新建自定义侧边栏目，绑定一个或多个 115 目录并独立设定刮削策略（番号刮削、TMDB/豆瓣院线刮削、目录合集、纯本地平铺）。
